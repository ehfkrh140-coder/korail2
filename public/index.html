KTX 잔여석 모니터링 알림판

지정한 날짜·구간·시간대의 KTX 열차를 보수적인 간격으로 실제 조회하고, 일반실·특실·입석·자유석 가능 상태가 발견될 때만 화면과 소리로 알립니다.

서버 상태 확인 중 현재 시각 --:--:--

중요 안내

  • 이 프로그램은 자동 예매 봇이 아니며, 자동 로그인·자동 예약·자동 결제·좌석 자동 선택을 하지 않습니다.
  • 자동화 탐지 우회, CAPTCHA 우회, CODE -8003 회피 목적의 기능을 넣지 않습니다.
  • 잔여석 발견 후 실제 예매와 결제는 사용자가 KORAIL 사이트 또는 코레일톡에서 직접 진행해야 합니다.
  • 조회 간격은 최소 20초 이상만 허용하며, 실패해도 즉시 무한 재시도하지 않습니다.
KORAIL 예매 사이트 열기

조건 입력 영역

여러 조건을 동시에 조회합니다. 기본값은 현재 필요한 왕복 KTX 조건입니다.

제어 영역

시간이 되면 알림만 울리는 것이 아니라, 서버가 실제 KORAIL 조회를 수행한 뒤 잔여석이 있을 때만 알립니다.

잔여석 발견!

자동 예매는 하지 않습니다. KORAIL 사이트 또는 코레일톡에서 사용자가 직접 예약/결제하세요.

결과 표시 영역

조건별 마지막 조회 시각, 열차 목록, 좌석 상태, 오류 메시지를 따로 표시합니다.

사용 방법

  1. npm run dev를 실행하고 http://localhost:3001에 접속합니다.
  2. 조건과 승객 수, 시간 범위, 조회 간격을 확인합니다.
  3. 즉시 1회 조회로 현재 조건이 조회되는지 확인합니다.
  4. 모니터링 시작을 누르면 각 주기마다 실제 KORAIL 조회를 수행합니다.
  5. 잔여석 발견 알림이 뜨면 사용자가 직접 KORAIL 또는 코레일톡에서 예약합니다.
