중요 안내

  • 이 앱은 KORAIL API, 내부 HTML 엔드포인트, hidden form 조합 요청을 직접 호출하지 않습니다.
  • 사용자가 직접 브라우저에서 KORAIL 접속, 로그인, 조건 입력, 최초 조회를 완료해야 합니다.
  • 프로그램은 연결된 브라우저 화면의 조회/다시조회/새로고침과 DOM 읽기만 수행합니다.
  • 자동 로그인, 자동 예매, 예약 버튼 클릭, 결제, 좌석 선택, CAPTCHA/탐지 우회는 하지 않습니다.
  • 전부 매진, 예약대기만 있음, 로딩 중, 열차 목록을 읽지 못한 경우에는 알림을 울리지 않습니다.

1. 브라우저 화면 연결

브라우저를 열고 사용자가 직접 코레일 예매 페이지에서 조건을 입력한 뒤 열차 목록 화면까지 이동하세요.

연결 대상 조건 예: 광명 → 부산 / 2026-05-23 / 09:00~13:00, 부산 → 광명 / 2026-05-24 / 원하는 시간대. 조건 입력은 코레일 화면에서 사용자가 직접 합니다.

  • 이 프로그램은 자동 예매 봇이 아니며, 자동 로그인·자동 예약·자동 결제·좌석 자동 선택을 하지 않습니다.
  • 자동화 탐지 우회, CAPTCHA 우회, CODE -8003 회피 목적의 기능을 넣지 않습니다.
  • 잔여석 발견 후 실제 예매와 결제는 사용자가 KORAIL 사이트 또는 코레일톡에서 직접 진행해야 합니다.
  • 조회 간격은 최소 20초 이상만 허용하며, 실패해도 즉시 무한 재시도하지 않습니다.

    3. 현재 화면에서 읽은 열차 목록

    이 표는 KORAIL 서버 응답을 직접 파싱한 것이 아니라, 연결된 브라우저 화면 DOM에서 읽은 텍스트입니다.

    사용 방법

    1. npm run dev를 실행하고 http://localhost:3001에 접속합니다.
    2. 브라우저 열기를 누른 뒤, 열린 브라우저 주소창에서 KORAIL 예매 사이트에 직접 접속합니다.
    3. 사용자가 직접 로그인하고 원하는 날짜·구간·승객 조건을 입력해 열차 목록 화면까지 이동합니다.
    4. 현재 코레일 화면 연결을 누릅니다.
    5. 즉시 1회 화면 갱신 및 검사로 화면 DOM 읽기가 되는지 확인합니다.
    6. 모니터링 시작을 누르면 보수적인 간격으로 현재 화면을 갱신하고 잔여석을 검사합니다.
    7. 잔여석 발견 알림이 뜨면 사용자가 직접 KORAIL 화면에서 예매합니다.

    결과 표시 영역

    조건별 마지막 조회 시각, 열차 목록, 좌석 상태, 오류 메시지를 따로 표시합니다.

    사용 방법

    1. npm run dev를 실행하고 http://localhost:3001에 접속합니다.
    2. 조건과 승객 수, 시간 범위, 조회 간격을 확인합니다.
    3. 즉시 1회 조회로 현재 조건이 조회되는지 확인합니다.
    4. 모니터링 시작을 누르면 각 주기마다 실제 KORAIL 조회를 수행합니다.
    5. 잔여석 발견 알림이 뜨면 사용자가 직접 KORAIL 또는 코레일톡에서 예약합니다.
  • Playwright, Puppeteer, Selenium 같은 자동화 브라우저를 사용하지 않습니다.
  • 로그인은 일반 Chrome에서 사용자가 직접 해야 합니다.
  • 분석 결과는 보조 판단이며, 최종 예약 가능 여부는 KORAIL 화면에서 직접 확인해야 합니다.
  • 캡차, 보안 확인, 결제 과정을 우회하거나 자동 처리하지 않습니다.

    아직 분석 전입니다.

    사용 방법

    1. 터미널에서 npm run dev를 실행합니다.
    2. 이 페이지가 열리지 않으면 Chrome에서 http://localhost:3001에 접속합니다.
    3. 일반 Chrome에서 KORAIL 사이트를 열고 직접 로그인합니다.
    4. 위 고정 조건으로 사용자가 직접 열차를 조회합니다.
    5. 타이머가 울릴 때마다 직접 새로고침/조회 후 결과를 복사해 붙여넣습니다.
    6. 후보가 보이면 KORAIL 화면에서 직접 예약과 결제를 진행합니다.

    자주 발생하는 문제

    브라우저 알림이 뜨지 않아요.

    알림 허용 버튼을 누르고 Chrome 주소창 왼쪽의 사이트 설정에서 알림을 허용했는지 확인하세요.

    후보가 없다고 나오지만 KORAIL에는 버튼이 보여요.

    KORAIL 화면 텍스트 구조가 바뀌었을 수 있습니다. 분석은 보조 기능이므로 실제 화면 판단을 우선하세요.

    터미널에서 포트 오류가 나요.

    이미 3001번 포트를 사용하는 프로그램이 있을 수 있습니다. 종료하거나 PORT=3002 npm run dev로 실행하세요.

    프로그램을 종료하려면 어떻게 하나요?

    터미널에서 Ctrl + C를 누르면 로컬 서버가 종료됩니다.
