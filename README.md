# KTX 빈자리 확인 도우미

매진된 KTX 승차권을 사람이 직접 확인할 때 놓치는 일을 줄이기 위한 **로컬 수동 보조 프로그램**입니다. KORAIL 사이트를 자동으로 조작하지 않고, 사용자가 일반 Chrome에서 직접 로그인·조회·예약·결제를 진행하는 흐름을 전제로 합니다.

## 1. 이 프로그램이 하는 일

- 로컬 웹페이지(`http://localhost:3001`)를 제공합니다.
- 사용자가 직접 KORAIL에서 조회한 결과 텍스트를 붙여넣으면 빈자리 후보를 분석합니다.
- 반복 확인을 잊지 않도록 타이머, 알림음, 브라우저 알림을 제공합니다.
- 아래 두 조건을 고정으로 확인합니다.

| 구분 | 날짜 | 구간 | 시간 범위 | 승객 | 좌석 | 열차 |
| --- | --- | --- | --- | --- | --- | --- |
| 왕복 1 | 2026년 5월 23일 | 광명 → 부산 | 09:00 이상 13:00 이하 | 성인 1명 | 일반실/특실 무관 | KTX 계열 우선 |
| 왕복 2 | 2026년 5월 25일 | 부산 → 광명 | 09:00 이상 15:00 이하 | 성인 1명 | 일반실/특실 무관 | KTX 계열 우선 |

## 2. 이 프로그램이 하지 않는 일

- 자동 로그인하지 않습니다.
- Playwright, Puppeteer, Selenium 같은 자동화 브라우저를 사용하지 않습니다.
- KORAIL 화면의 예약 버튼을 자동 클릭하지 않습니다.
- 결제 또는 결제 직전 단계까지 자동 진행하지 않습니다.
- 캡차, 보안 확인, 자동화 탐지를 우회하지 않습니다.

> 최종 예약 가능 여부는 반드시 KORAIL 실제 화면에서 사용자가 직접 확인해야 합니다.

## 3. Node.js 설치 방법 개요

1. Chrome에서 [Node.js 공식 사이트](https://nodejs.org/)를 엽니다.
2. LTS 버전을 내려받아 설치합니다.
3. 설치 후 새 터미널을 열고 아래 명령으로 설치 여부를 확인합니다.

```bash
node -v
npm -v
```

버전 번호가 보이면 준비가 끝난 것입니다.

## 4. 저장소 내려받기 또는 폴더 열기

이미 이 폴더를 받은 상태라면 터미널에서 폴더로 이동합니다.

```bash
cd /workspace/korail2
```

Git으로 내려받는 경우에는 아래처럼 받은 뒤 폴더로 이동합니다.

```bash
git clone <저장소 주소>
cd korail2
```

## 5. 프로그램 실행 방법

이 저장소는 외부 npm 의존성이 없으므로 `npm install` 없이 실행할 수 있습니다.

```bash
npm run dev
```

터미널에 아래와 비슷한 문구가 보이면 실행 중입니다.

```text
KTX 빈자리 확인 도우미가 실행 중입니다: http://localhost:3001
종료하려면 터미널에서 Ctrl+C를 누르세요.
```

## 6. 브라우저에서 접속하기

Chrome 주소창에 아래 주소를 입력합니다.

```text
http://localhost:3001
```

페이지가 열리면 `KORAIL 예매 사이트 열기` 버튼을 눌러 KORAIL을 새 탭으로 열 수 있습니다.

## 7. Chrome에서 KORAIL에 직접 로그인하기

1. 일반 Chrome에서 KORAIL 예매 사이트를 엽니다.
2. 사용자가 직접 로그인합니다.
3. 자동화 브라우저나 자동 로그인 도구를 사용하지 않습니다.
4. 보안 확인이 나오면 KORAIL 안내에 따라 사용자가 직접 처리합니다.

## 8. KORAIL 조회 결과 복사 및 붙여넣기

1. KORAIL에서 조건에 맞게 열차를 직접 조회합니다.
2. 화면에 보이는 열차 목록 영역을 마우스로 드래그해 복사합니다.
3. 이 프로그램의 `조회 결과 붙여넣기` 입력창에 붙여넣습니다.
4. `빈자리 분석` 버튼을 누릅니다.
5. 후보가 표시되면 KORAIL 탭으로 돌아가 실제 예약 가능 여부를 직접 확인합니다.

분석기는 다음 기준으로 후보를 찾습니다.

- 출발 시간이 고정 조건의 시간 범위 안에 있는지 확인합니다.
- `광명`, `부산` 등 구간 문구가 포함되어 있는지 확인합니다.
- `KTX`, `KTX-산천`, `KTX-청룡` 등 KTX 계열 문구가 있는지 확인합니다.
- `예약`, `예매`, `선택`, `가능`, `특실`, `일반실` 문구를 가능 신호로 봅니다.
- `매진`, `입석`, `자유석`, `예약대기`, `대기` 문구가 있으면 제외합니다.

## 9. 빈자리 발견 시 해야 할 일

후보가 보이거나 알림이 울리면 즉시 KORAIL 화면을 직접 확인하세요. 이 프로그램은 예매 버튼을 대신 누르지 않습니다. 예약, 본인확인, 결제는 모두 사용자가 직접 진행해야 합니다.

## 10. 프로그램 종료 방법

실행 중인 터미널에서 아래 키를 누릅니다.

```text
Ctrl + C
```

종료 후 `http://localhost:3001` 페이지가 더 이상 열리지 않는 것이 정상입니다.

## 11. 문법 확인

수정 후에는 아래 명령으로 기본 문법을 확인할 수 있습니다.

```bash
npm run check
```

## 12. 자주 발생하는 오류 해결

### `npm error code EJSONPARSE`가 나와요

`package.json` 문법이 깨졌을 때 발생합니다. 쉼표 누락, 따옴표 누락, 중복된 script 항목이 없는지 확인하세요.

### `http://localhost:3001`이 열리지 않아요

- `npm run dev`가 계속 실행 중인지 확인하세요.
- 터미널에 오류가 있는지 확인하세요.
- 다른 프로그램이 3001번 포트를 사용 중이면 아래처럼 다른 포트를 지정할 수 있습니다.

```bash
PORT=3002 npm run dev
```

이 경우 접속 주소도 `http://localhost:3002`로 바뀝니다.

### 알림이 뜨지 않아요

- 페이지의 `브라우저 알림 허용` 버튼을 누르세요.
- Chrome 주소창 왼쪽의 사이트 설정에서 알림 권한을 허용하세요.
- 알림이 차단되어도 타이머 표시와 알림음은 사용할 수 있습니다.

### 후보가 없다고 나오는데 실제 화면에는 버튼이 보여요

KORAIL 화면 텍스트 구조가 바뀌었거나 복사된 텍스트가 줄 단위로 잘리지 않았을 수 있습니다. 분석 결과는 보조 판단일 뿐이며 실제 KORAIL 화면 판단을 우선하세요.

### KORAIL에서 자동화 관련 경고가 나와요

이 프로그램은 KORAIL을 자동 조작하지 않습니다. 자동화 브라우저, 자동 로그인 도구, 매크로 도구를 함께 사용하고 있지 않은지 확인하고 일반 Chrome에서 직접 진행하세요.
